# Dovetail — Dovetail-Driven Wiring for .NET

**AOT & Trim Safe**
Generated code requires zero runtime reflection — fully compatible with
        .NET Native AOT and IL trimming.

**Module Wiring**
Define services, configuration, logging, and hosting as assembly-level
        joints resolved at build time by a Roslyn source generator.

**Composable**
First-class support for Generic Host, ASP.NET Core, Autofac, DryIoc,
        Serilog, and .NET Aspire — all wired automagically.
